# 🍽️ Food Ordering Behaviour Analytics

## Food Ordering Behaviour and Consumer Trends: A Structured Analysis of Choices and Habits

A data analytics and visualization project that analyzes **food ordering behaviour, consumer preferences, order values, delivery performance, and customer ratings** using **Tableau**.

---

## 📌 Project Overview

The food delivery industry generates large amounts of customer and order data. This project analyzes food ordering behaviour to identify meaningful patterns related to:

- 🏙️ City-wise food ordering demand
- 🍛 Cuisine preferences
- 🍽️ Meal-type preferences
- 💰 Order value
- 🚚 Delivery fees and delivery-time patterns
- ⭐ Customer ratings
- 👥 Customer age groups
- 🏪 Restaurant segments
- 🤝 Company / ordering groups

The project uses a structured dataset containing **50,000 food-order records** and presents the analysis through an interactive **Tableau Dashboard** and **Tableau Story**.

---

## 🎯 Problem Statement

Food ordering behaviour varies according to location, cuisine, meal type, customer characteristics, restaurant segment, and other contextual factors.

Without proper analysis and visualization, it can be difficult to identify:

- Which cities have higher order demand
- Which cuisines are preferred by customers
- Which meal types contribute more to order value
- How delivery-time values are distributed
- How order value compares with delivery fees
- How customer ratings vary
- How ordering behaviour differs across age groups and restaurant segments

Therefore, this project aims to transform raw food-ordering data into meaningful visual insights using Tableau.

---

## 🎯 Objectives

The main objectives of this project are:

- Analyze food ordering trends and consumer behaviour.
- Identify popular cuisines and meal types.
- Compare food-order demand across different cities.
- Analyze order value and delivery fees.
- Study delivery-time patterns.
- Understand customer rating patterns.
- Analyze ordering behaviour across age groups.
- Compare restaurant segments.

- Develop an interactive Tableau Dashboard.

# 💡 Insights & Tableau Story

## 💡 Key Insights

### 🏙️ City-wise Demand

Mumbai records the highest displayed order volume with **8,443 orders**, followed by Pune with **8,354** and Bangalore with **8,353**.

### 🍰 Cuisine Preferences

Customer preferences are relatively balanced across the six major cuisine categories, with **Desserts having the largest displayed share**.

### 🍳 Meal-Type Revenue

**Breakfast** contributes the highest displayed order value at **6,924,753**, followed by Snacks, Lunch, and Dinner.

### 🚚 Delivery-Time Distribution

The dashboard provides a distribution of order counts across different delivery-time values, allowing users to compare frequently occurring and less frequent delivery-time values.

### 💰 Order Value & Delivery Fee

The scatter visualization compares **Order Value and Delivery Fee**, with observations distributed across the major cities.

### 🏙️ City & Cuisine Relationship

The heatmap compares cuisine demand across cities and highlights differences in local food preferences.
