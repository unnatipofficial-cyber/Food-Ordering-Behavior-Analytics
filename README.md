# 🍽️ Food Ordering Behaviour Analytics

### Food Ordering Behaviour and Consumer Trends: A Structured Analysis of Choices and Habits

A data analytics and visualization project that analyzes food ordering patterns, consumer preferences, order values, delivery performance, and customer ratings using **Tableau**.

---

## 📌 Project Overview

The food delivery industry generates large amounts of customer and order data. This project analyzes food ordering behaviour to identify useful patterns related to cuisine preferences, meal types, city-wise demand, order value, delivery time, and customer ratings.

The project uses a structured dataset of **300 food orders** and presents the analysis through interactive Tableau visualizations and dashboards.

---

## 🎯 Objectives

- Analyze food ordering trends and customer behaviour.
- Identify popular cuisines and meal types.
- Compare order demand across different cities.
- Analyze order value and delivery charges.
- Study delivery time and delivery categories.
- Understand customer rating patterns.
- Identify monthly ordering trends.
- Create an interactive Tableau dashboard.

---

## 📊 Key Analysis Areas

The project includes analysis of:

- Orders by City
- Orders by Cuisine
- Order Value by Meal Type
- Average Delivery Time by City
- Orders by Delivery Category
- Monthly Order Trend
- Customer Rating Distribution
- Order Value by Cuisine
